## 一、结论先说

**结构已对齐，剩余差异全部来自"内容"而非"结构"。** 具体：

| 类别 | 说明 | 处理 |
|---|---|---|
| **结构性偏差（已修 10 处）** | 侧栏选中态、底部按钮结构、聊天列限宽、卡片表头变体等 | 已按原型 CSS 逐条改正（见 §三） |
| **内容差异（可接受）** | 前端用真实数据（`156.224.28.147`、环境标签）与自拟文案，效果图用演示值 | 属预期，**不是缺陷**；接真后端后由数据驱动 |
| **待修内容差异** | 欢迎页文案、失败态文案、工具面板条目 | 列入 §四 |

> **重要**：MAD 是**排查工具，不是验收标准**。它的绝对值受内容差异主导（聊天区文案换行、IP 字符串不同都会抬高），所以本文用它来**排序和定位**，验收仍以《前端实现规格》第 8 节清单 + 分区人工核对为准。

## 三、已修正的结构性偏差（10 处）

全部以原型 `gen_proto10.py` 的 CSS 数值为准，不靠目测。

### 侧栏（本轮修 5 处）

| 元素 | 原型 | 修正前 | 现状 |
|---|---|---|---|
| 选中态导航项 | `.navitem.on` = `accent-soft` 底 + `accent` 文字 + 600 字重 | `panel2` 底 + 左侧 2px 竖条 | ✅ |
| 导航行 | `h28 / padding 0 8px / radius 6` | `h30 / padding 0 14px / 无圆角` | ✅ |
| 导航容器 | `.nav` = `padding 0 6px 6px`（内容内缩） | 无内缩 | ✅ |
| 分组标题 | `padding 9px 10px 3px` + **600 字重** | `px14 pt10 pb5` + 400 字重 | ✅ |
| **侧栏底部** | 2 列网格 + **第 3 个按钮跨列**「⚙ 连接管理 · 凭据管理」，`h30`、`panel2` 底 + `--border` 边 | 4 个独立按钮（连接管理/凭据管理 分开） | ✅ |

> 底部这条是**全局恒定差异（所有状态 r8c1≈32）的根因**——它出现在每一张图里，说明是结构而非内容问题。

### 卡片与布局（M5-6 / M5-9 期间修 5 处）

1. `.stream`/`.composer` 常态限宽 **1040** 居中，≥1700 才 1120
2. 快捷操作 chips 需带 `--border` 边框
3. 审批卡：根因在**卡内**、h4 为「需要你的批准」、`server_id` 等宽字体
4. 失败态工具卡用 `.hd` 结构（不是 `.toolhd`）；总结卡 h4「任务已完成」、对比数值绿色、后续建议用 `<div>` 而非 `<ol>`
5. 失败后的分析块是**纯文本块**，不是卡片
